# 呢喃课表用户协议

> 版本：v1.0　生效日期：2026-10-24

本协议是您（下称“用户”）与呢喃课表开发者 JesseLee（下称“我们”）之间关于使用「呢喃课表」HarmonyOS 应用（下称“本应用”）所订立的协议。
本应用是基于上游 Flutter 项目「南哪课表」（作者 idealclover，Apache-2.0）的 HarmonyOS / ArkTS 原生重写版本。本应用与南京大学及各高校、教务系统均无隶属或代理关系，不是学校官方应用。
请您在使用本应用前仔细阅读并充分理解本协议全部内容，特别是免除或限制责任的条款。您首次启动本应用并点击同意，即表示您已阅读、理解并同意本协议及《呢喃课表隐私政策》。如您不同意，请退出并不使用本应用。

## 一、协议的接受与变更

您通过点击“同意”、继续使用本应用等方式接受本协议。若您为无民事行为能力人或限制民事行为能力人，请在监护人陪同下阅读并由监护人决定是否同意。

我们可能根据法律法规、产品功能或运营情况变化更新本协议。更新后的协议将在应用内公布并标注生效日期；涉及您主要权利义务的重大变更，我们会通过弹窗等显著方式再次征得您的同意。变更生效后您继续使用本应用的，视为接受变更后的协议。

## 二、服务内容

本应用是一款本地优先的课程表工具，主要功能包括：课表与课程的新增、编辑、删除、多课表管理、周次切换、桌面小组件；通过应用内网页导入各高校教务系统中的课程；课表分享码与二维码的生成、解析和导入；浏览讲座信息并加入课表；主题色、深浅色、背景图等外观设置。

本应用免费提供，无账号体系，也没有我们自建的账号或课程数据服务器，课程与设置数据均保存在您的设备本地。讲座信息由上游项目作者维护的公开服务提供，其可用性可能受第三方影响。

我们可能对服务内容进行增加、调整或停止部分功能，具体以本应用实际提供的功能为准。

## 四、用户行为规范

您应遵守法律法规、公序良俗以及所在学校的管理规定，仅导入您本人或已获得授权的课程信息。

您不得：使用自动化脚本、爬虫或其他方式高频访问学校教务系统或讲座服务；绕过、破解学校身份认证或访问控制；攻击、干扰或试图破坏本应用、学校系统或讲座服务的正常运行；利用本应用传播违法、侵权或虚假信息；未经授权将本应用用于商业代导入、售卖课表或其他营利活动；对本应用进行反向工程（开源许可证明确允许的除外）。

## 五、教务导入与账号安全

教务导入是在应用内嵌的网页中打开您所选学校教务系统官方页面，由您自行输入账号、密码并完成登录；相关页面与身份验证由学校提供和控制，课程解析脚本在本地运行。

我们不会读取、保存或上传您的账号密码；账号密码由学校页面直接提交至学校服务器。学校页面自身的“记住密码”、Cookie 等本地存储行为由学校网页控制，刷新导入页时本应用会清除网页 Cookie。

您应妥善保管账号和密码，遵守学校关于账号使用和信息安全的规定。教务系统可能更新页面结构或限制访问，导致导入失败或课程信息不准确；导入结果仅供您参考，请以学校教务系统为准确来源。
